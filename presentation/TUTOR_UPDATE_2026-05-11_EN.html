Now

  • Anonymous-first — no account, evidence in localStorage, JSON export/import for portability
  • Two LLM layers — per-evidence classification + case-level legal AI (risk, charges, next steps)
  • PDF redesigned — exec-summary card, numbered evidence exhibits, embedded AI assessment, page footer

  • Browser-side hash verifier — police/lawyers can verify SHA-256 without trusting our server
  • Auto-resync — local + backend evidence reconcile on every report fetch (no manual "sync" button)

Architecture & Classifier

One LLM call · one Pydantic schema · no hallucinated paragraphs.

Stack

OCRTesseract → OpenAI Vision fallback
PDFReportLab (A4, court-ready)

Classifier guarantees

  • 16 categories + 11 statutes as Python enums — model cannot invent
  • No silent fallback: schema-fail → HTTP 503
  • Few-shot with idiom + obfuscation + extremist-code + doxxing examples
class ClassificationResult(BaseModel): severity: Severity # low / medium / high / critical categories: list[Category] confidence: float requires_immediate_action: bool summary: str summary_de: str applicable_laws: list[GermanLaw] client.chat.completions.parse( model="gpt-4o-mini", response_format=ClassificationResult, messages=[…] )

A second LLM layer (analyze_case_legally) runs over all evidence + the victim's context once a case has multiple incidents. Returns: free-text assessment (DE/EN), escalation risk + reason, strongest charges with strength scores, prioritised next steps with deadlines. Embedded in the Strafanzeige PDF.

SafeVoice · Tutor Update 3 / 5
Evidence chain · Test results

Police-grade evidence, end-to-end.

Chain of custody

  • SHA-256 hash per evidence (sha256:…)
  • UTC timestamp with timezone (legal requirement)
  • archive.org backup link when scraping URLs
  • Browser verifier — Web Crypto API recomputes the hash from pasted text. Same algorithm as the backend (hashlib.sha256) — bit-identical. Police/lawyer needs no trust in our server.

PDF deliverable

  • Letterhead masthead with case-id (monospace)
  • Executive summary card — readable in 3 seconds
  • Numbered evidence exhibits with severity-coded dots
  • AI assessment block — typographically marked as AI's voice, not victim's
  • Page footer, 30 mm punch margin, fold mark

Idea & Motivation

Online hate is daily, and mostly invisible to the legal system.

every 3 min
someone in Germany is harassed online
(BKA, 2023)
~90%
of incidents go unreported — too complex, too slow, too painful
~€120/h
lawyer consultation — out of reach for most victims

Why most cases never reach the police

  1. Victims don't know which laws apply. 16 distinct offenses in Germany — Beleidigung (§185), Bedrohung (§241), Volksverhetzung (§130), Stalking (§238), Doxxing (§126a), Intimate-image violations (§201a). Picking the right one is a research task.
  2. Evidence disappears. Platforms delete posts. Accounts get suspended. Screenshots without checksums aren't court-grade.
  3. Filing a Strafanzeige is paperwork. Facts, time of offense, location, statute list, postal addresses — hours of work, often while still in shock.

The gap: a fast, anonymous, evidence-preserving tool that translates raw harassment into a document the police can actually act on.

How it works

One controlled workflow, four steps.

SafeVoice is a focused evidence-to-action workflow — not a generic chatbot. The job: take harassment in, produce a court-ready complaint out.

STEP 1

Document

Paste text, URL or screenshot — 10 s

→
STEP 2

Classify

Statutes, severity, recommendations — 3 s

→
STEP 3

Preserve

SHA-256 hash, archive link, timestamp — instant

→
STEP 4

File

Strafanzeige PDF, Onlinewache flow — 1 click

Anonymous-first: data lives in your browser. No account, no tracking, no server-side personal data unless you explicitly submit. The same case can be enriched over time — append new evidence, edit context, change author handles — and the criminal complaint updates with it.

Functions & Features

Built around what police and victims actually need.

For victims

  • Three input paths — paste text · paste URL · upload screenshot
  • Anonymous-first — no account, no email, JSON export to back up cases
  • Inline editing — add new incidents to existing cases, edit context + author handles after the fact
  • Onlinewache flow — 3-step copy/open/paste guide per Bundesland
  • HateAid handoff — direct referral with their hotline + escalation path
  • Bilingual — DE + EN UI, classifier also handles TR + AR

For the report recipient

  • Executive-summary PDF card — police read the case in 3 seconds
  • Numbered evidence exhibits with severity-coded dots, italic quote, statute list
  • AI-assisted legal assessment embedded — typographically marked so it's clearly the AI's voice
  • SHA-256 verification — every piece of evidence has an independently verifiable hash
  • Multiple templates — Strafanzeige · NetzDG removal · general report
  • .eml export — double-click opens Mail with attachments pre-attached

AI

One LLM call, one Pydantic schema, no hallucinated paragraphs.

Two AI layers

  1. Per-evidence classifier — gpt-4o-mini reads each piece, returns severity, statutes, summary (DE+EN), recommended actions. Pydantic Structured Outputs prevent hallucinated paragraphs.
  2. Case-level legal AI — second pass over all evidence + victim context produces: free-text assessment, escalation risk, strongest charges with strength scores, prioritised next steps with deadlines.

Few-shot prompt covers the hard cases

  • Idiom false-positive — "Das bringt mich um" → low
  • Obfuscation — "du H*re" → critical (asterisk doesn't change intent)
  • Extremist code — "1488" → §130 Volksverhetzung
  • Doxxing — address + phone exposed → §126a / §238
  • Context-sensitive — same insult from ex-partner → §238 Stalking instead of §241
class ClassificationResult(BaseModel): severity: Severity # 4 levels categories: list[Category] # 16 enum confidence: float requires_immediate_action: bool summary: str # EN summary_de: str # DE applicable_laws: list[GermanLaw] client.chat.completions.parse( model="gpt-4o-mini", response_format=ClassificationResult, messages=[…]) # OCR fallback when Tesseract missing # (Vercel serverless has no system packages): # gpt-4o-mini Vision → returns # {text, sender_handle, platform_hint}

No silent fallback. Schema-fail → HTTP 503 instead of guessing — a weak classification would be worse than none for a police document.

DSGVO-by-design

  • Anonymous-first — default path needs no account
  • Data minimization (Art. 5) — only what's needed for the complaint
  • Local data sovereignty — cases live in browser localStorage; JSON export for user-owned backup

Challenges

What was hard, and what we still don't know.

Engineering / product challenges

  • Routing on Vercel for FastAPI. Vercel's filesystem-based routing strips paths. Solved with an ASGI proxy that reads the original path from a query param.
  • OCR on serverless. Vercel has no system packages — Tesseract isn't available. Solved with a two-tier OCR: Tesseract locally, OpenAI Vision (gpt-4o-mini) as serverless fallback.
  • Local + backend evidence drift. Cases live in localStorage but the legal AI runs server-side. Built auto-reconciliation: hash compare on every report fetch, push only the missing pieces.
  • Trauma-aware UX. Cut combat metaphors ("dich wehren"), pulsing critical badges, engineering jargon ("Resend-Integration") — replaced with calmer phrasing.

Open ethical / legal questions

  • AI in a police-facing document — is typographic separation + a disclaimer enough, or does any AI-generated text in a Strafanzeige risk improperly influencing investigations?
  • Schema drift — we encode 11 statutes today. German law evolves; how do we keep the enum up to date without silent miss-classification?
  • Anonymity vs. accountability — anonymous-first is DSGVO-stronger and lower-friction, but means we can't easily audit aggregate harm or hand long-term cases to lawyers.
  • Trust transfer — SafeVoice should be carried by an established NGO (HateAid) before scaling. Without it, victims may not trust an individual-run tool.
  • Linguistic edge cases — irony, dialects, mixed-language threats. The classifier is calibrated for clear cases; edge cases need human review.

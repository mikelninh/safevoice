SafeVoice · AI Flow 08 / 12
DB architecture · the pivot

One change unlocked everything: user_id became optional.

Login-first meant no account → no case — a barrier for someone in crisis. The login was the threat model.

Before · login-first

cases user_id FK → users.id # required title, context, ...
→

Today · anonymous-first

cases user_id FK → users.id NULL # optional! anonymous_token UNIQUE # browser-local title, context, severity

Cases live without a user — in the browser. Login = optional upgrade for NGOs.

SafeVoice · Iterations 10 / 12
Insights · what I'd tell my past self

Three things this project changed in my head.

01 · Architecture > prompting

The model can't return what the schema doesn't allow. Two layers beat one big call.

02 · AI replaces grunt work — not judgment

Hours of paperwork → seconds. The decision stays human. No silent fallback: a weak guess is worse than none.

03 · UX is architecture

"No account required" forced a schema rewrite — and the strongest model wasn't the right one. 7.4× cheaper, same accuracy.

Backup · evidence preservation

SHA-256. archive.org. Browser verifier.

Each piece of evidence gets a SHA-256 hash over the exact content at capture time — a 64-character fingerprint. Change one character, the hash changes completely.

Additionally:

  • UTC timestamp with timezone (legally required)
  • archive.org backup link (when scraping a URL)
  • Hash chain between pieces of evidence — tampering with one invalidates the chain

NEW  Browser verifier. Police or lawyer pastes the original content; the browser computes the hash live via Web Crypto API — no trust in our server required.

Backup · FAQ (also on safevoice.app/faq)

Six questions I get asked most.

1 · Is this legally binding evidence?

The PDF isn't a verdict — it's a structured complaint. SHA-256 hash + archive.org + UTC timestamp make the screenshot forensically verifiable.

2 · Can the AI hallucinate a wrong § StGB?

No. The 16 categories are a Pydantic enum enforced via Structured Outputs. The model cannot return a value outside the enum. <0.7 confidence flags human review.

3 · What happens to my data?

Anonymous-first. localStorage by default. Server processes in Frankfurt without content logging. GDPR Art. 25 by design.

4 · Why open source?

Victims shouldn't have to trust a black box. NGOs need to audit and self-host. Prosecutors can verify our hash-chain logic line by line.

5 · What about false positives?

86 % accuracy = 14 % needs review. PDF shows confidence + reasoning per classification. Human confirms before filing.

6 · Who pays for this?

Free for victims, forever. NGO/government pilots cover infra ($90/mo at 10k cases). Funding track: Prototype Fund, Schöpflin, Bertelsmann.
